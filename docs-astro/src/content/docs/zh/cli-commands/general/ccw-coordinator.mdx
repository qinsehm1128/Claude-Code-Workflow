# /ccw-coordinator

通用命令编排工具 - 分析需求、推荐命令链，并按顺序执行，同时支持状态持久化。

## 概述

`/ccw-coordinator` 命令是一个通用编排器，能够处理任何 CCW 工作流，通过分析任务需求并推荐最优命令链。

**参数**：
- `[task description]`：要编排的任务（必填）

**执行模型**：伪代码指导 - Claude 根据上下文智能执行每个阶段。

## 核心概念：最小执行单元

**定义**：必须作为原子组一起执行的命令，以实现有意义的工作流里程碑。

### 执行单元示例

| 单元名称 | 命令 | 用途 |
|-----------|----------|---------|
| **快速实现** | `/workflow:lite-plan` → `/workflow:lite-execute` | 轻量规划和执行 |
| **多 CLI 规划** | `/workflow:multi-cli-plan` → `/workflow:lite-execute` | 多视角分析 |
| **Bug 修复** | `/workflow:lite-fix` → `/workflow:lite-execute` | Bug 诊断和修复 |
| **验证规划** | `/workflow:plan` → `/workflow:plan-verify` → `/workflow:execute` | 带验证的规划 |
| **TDD 规划** | `/workflow:tdd-plan` → `/workflow:execute` | 测试驱动开发 |

## 用法

```bash
# 让协调器分析并推荐
/ccw-coordinator "Implement user authentication"

# 协调器将：
# 1. 分析任务需求
# 2. 推荐最优命令链
# 3. 按顺序执行命令
# 4. 全程跟踪状态
```

## 执行流程

### 阶段 1：分析需求

```javascript
async function analyzeRequirements(taskDescription) {
  const analysis = {
    goal: extractGoal(taskDescription),
    scope: determineScope(taskDescription),
    complexity: calculateComplexity(taskDescription),
    task_type: classifyTask(taskDescription),
    constraints: identifyConstraints(taskDescription)
  };
  return analysis;
}
```

**输出**：
- 目标：需要完成的内容
- 范围：受影响的模块/组件
- 复杂度：simple/medium/complex
- 任务类型：feature、bugfix、refactor 等
- 约束条件：时间、资源、依赖

### 阶段 2：推荐命令链

```javascript
async function recommendCommandChain(analysis) {
  const { inputPort, outputPort } = determinePortFlow(analysis.task_type, analysis.constraints);
  const chain = selectChainByPorts(inputPort, outputPort, analysis);
  return chain;
}
```

**输出**：
- 选择的工作流级别
- 包含单元的命令链
- 执行模式 (mainprocess/async)
- 预期产物

### 阶段 3：用户确认

### 阶段 4：顺序执行命令链

```javascript
async function executeCommandChain(chain, analysis) {
  const sessionId = `ccw-coord-${Date.now()}`;
  const state = {
    session_id: sessionId,
    status: 'running',
    analysis: analysis,
    command_chain: chain.map((cmd, idx) => ({ ...cmd, index: idx, status: 'pending' })),
    execution_results: []
  };

  // Save initial state
  Write(`.workflow/.ccw-coordinator/${sessionId}/state.json`, JSON.stringify(state, null, 2));

  for (let i = 0; i < chain.length; i++) {
    const cmd = chain[i];
    console.log(`[${i+1}/${chain.length}] Executing: ${cmd.command}`);

    // Update status to running
    state.command_chain[i].status = 'running';
    Write(`.workflow/.ccw-coordinator/${sessionId}/state.json`, JSON.stringify(state, null, 2));

    // Execute command via CLI
    const taskId = Bash(
      `ccw cli -p "${escapePrompt(prompt)}" --tool claude --mode write`,
      { run_in_background: true }
    ).task_id;

    // Save execution record
    state.execution_results.push({
      index: i,
      command: cmd.command,
      status: 'in-progress',
      task_id: taskId,
      timestamp: new Date().toISOString()
    });
  }

  return state;
}
```

## 参数模式

| 命令类型 | 参数模式 | 示例 |
|--------------|------------------|---------|
| **规划** | `"task description"` | `/workflow:plan -y "Implement OAuth2"` |
| **执行（带计划）** | `--resume-session="WFS-xxx"` | `/workflow:execute -y --resume-session="WFS-plan-001"` |
| **执行（独立）** | `--in-memory` 或 `"task"` | `/workflow:lite-execute -y --in-memory` |
| **基于会话** | `--session="WFS-xxx"` | `/workflow:test-fix-gen -y --session="WFS-impl-001"` |
| **修复/调试** | `"problem description"` | `/workflow:lite-fix -y "Fix timeout bug"` |

## 注意事项

- **原子执行** - 不拆分最小执行单元
- **状态持久化** - 所有状态保存到 `.workflow/.ccw-coordinator/`
- **用户控制** - 执行前需确认
- **上下文传递** - 参数在命令间链式传递
- **恢复支持** - 可从 state.json 恢复
- **智能路由** - 基于端口的命令匹配
