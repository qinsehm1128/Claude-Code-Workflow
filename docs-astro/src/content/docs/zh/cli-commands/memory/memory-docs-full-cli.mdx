# /memory:docs-full-cli

使用批量 Agent 执行和自动工具降级为所有项目模块生成全面的 CLI 文档。

## 概述

`/memory:docs-full-cli` 命令使用 CLI 工具和智能批处理以及自动降级为项目中所有模块生成完整文档。

**参数**：
- `--tool <gemini|qwen|codex>`：主要工具（默认：gemini）
- `--path <directory>`：目标目录（默认：项目根目录）

**执行流程**：
1. 模块检测 → 2. 计划展示 → 3. 批量生成 → 4. 验证

## 特性

- **全量覆盖** - 为项目中所有模块生成文档
- **智能批处理** - 按深度分组模块（4 个模块/批）
- **自动降级** - gemini→qwen→codex 失败时自动降级
- **深度顺序** - 处理深度 N→0，深度内批次并行
- **智能过滤** - 自动检测并跳过 tests/build/config/docs

## 用法

```bash
# 生成全量文档
/memory:docs-full-cli

# 指定目标目录
/memory:docs-full-cli --path src/auth

# 使用特定工具
/memory:docs-full-cli --tool qwen
```

## 工具降级层次

```javascript
--tool gemini  →  [gemini, qwen, codex]  // default
--tool qwen    →  [qwen, gemini, codex]
--tool codex   →  [codex, gemini, qwen]
```

## 执行流程

### 阶段 1：模块检测与分析

```javascript
// Get module structure with classification
Bash({command: "ccw tool exec get_modules_by_depth '{\"format\":\"list\"}' | ccw tool exec classify_folders '{}'", run_in_background: false});

// OR with path parameter
Bash({command: "cd <target-path> && ccw tool exec get_modules_by_depth '{\"format\":\"list\"}' | ccw tool exec classify_folders '{}'", run_in_background: false});
```

**解析输出** `depth:N|path:<PATH>|type:<code|navigation>|...` 以提取模块路径、类型和数量。

**智能过滤**：基于项目技术栈自动检测并跳过 tests/build/config/vendor。

### 阶段 2：计划展示

- 解析 `--tool`（默认：gemini）
- 获取带分类的模块结构
- **智能过滤模块**（自动检测技术栈，跳过 tests/build/config）
- 构建工具降级顺序
- **展示过滤后的计划** 包含模块类型和数量
- **等待 y/n 确认**

### 阶段 3：批量文档生成

```javascript
let modules_by_depth = group_by_depth(all_modules);
let tool_order = construct_tool_order(primary_tool);

for (let depth of sorted_depths.reverse()) {  // N → 0
  let batches = batch_modules(modules_by_depth[depth], 4);

  for (let batch of batches) {
    let parallel_tasks = batch.map(module => {
      return async () => {
        let strategy = module.depth >= 3 ? "full" : "single";
        for (let tool of tool_order) {
          Bash({
            command: `cd ${module.path} && ccw tool exec generate_module_docs '{"strategy":"${strategy}","sourcePath":".","projectName":"${project_name}","tool":"${tool}"}'`,
            run_in_background: false
          });
          if (bash_result.exit_code === 0) {
            report(`✅ ${module.path} (Layer ${layer}) docs generated with ${tool}`);
            return true;
          }
        }
        report(`❌ FAILED: ${module.path} (Layer ${layer}) failed all tools`);
        return false;
      };
    });
    await Promise.all(parallel_tasks.map(task => task()));
  }
}
```

### 阶段 4：验证

- 验证文档文件已创建
- 显示统计数据
- 展示生成文档的摘要

## 策略选择

| 模块深度 | 策略 | 描述 |
|--------------|----------|-------------|
| 深度 < 3 | single | 模块的单一文档 |
| 深度 >= 3 | full | 带子章节的全面文档 |

## 模块类型

| 类型 | 描述 | 文档关注点 |
|------|-------------|---------------------|
| **code** | 源代码模块 | API、类、函数 |
| **navigation** | 目录结构 | 组织、文件用途 |
