# Ccw Help

CCW 命令帮助系统。搜索、浏览、推荐命令。触发关键词："ccw-help"、"ccw-issue"。

## 概览

| 属性 | 值 |
|------|-----|
| **名称** | `ccw-help` |
| **版本** | 7.0.0 |
| **工具** | `Read`, `Grep`, `Glob`, `AskUserQuestion` |

## 参考

CCW 命令帮助系统，提供命令搜索、推荐、文档查看功能。

## 触发条件

- 关键词: "ccw-help", "ccw-issue", "帮助", "命令", "怎么用", "ccw 怎么用", "工作流"
- 场景: 询问命令用法、搜索命令、请求下一步建议、询问任务应该用哪个工作流

## 操作模式

### 模式 1：命令搜索

**触发条件**："搜索命令"、"find command"、"search"

**流程**：
1. 查询 `command.json` 的 commands 数组
2. 按名称、描述、分类过滤
3. 展示前 3-5 个相关命令

### 模式 2：智能推荐

**触发条件**："下一步"、"what's next"、"推荐"

**流程**：
1. 查询 `command.json` 中命令的 `flow.next_steps`
2. 解释为什么每个推荐适合当前场景

### 模式 3：文档查看

**触发条件**："怎么用"、"how to use"、"详情"

**流程**：
1. 在 `command.json` 中定位命令
2. 通过 `source` 路径读取源文件
3. 提供场景化示例

### 模式 4：新手引导

**触发条件**："新手"、"getting started"、"常用命令"

**流程**：
1. 查询 `essential_commands` 数组
2. 引导到合适的工作流入口

### 模式 5：CCW 命令编排

**触发条件**："ccw "、"自动工作流"、"自动选择工作流"、"帮我规划"

**流程**：
1. 分析用户意图（任务类型、复杂度、清晰度）
2. 自动选择工作流级别（1-4 或 Issue）
3. 基于工作流构建命令链
4. 获取用户确认
5. 执行命令链并进行 TODO 追踪

**支持的工作流**：
- **Level 1** (Lite-Lite-Lite)：超简快速任务
- **Level 2** (Rapid/Hotfix)：Bug 修复、简单功能、文档
- **Level 2.5** (Rapid-to-Issue)：从快速规划到 Issue 工作流的桥梁
- **Level 3** (Coupled)：复杂功能，包含规划、执行、审查、测试
- **Level 3 变体**：
  - TDD 工作流（测试先行开发）
  - Test-fix 工作流（调试失败的测试）
  - Review 工作流（代码审查和修复）
  - UI 设计工作流
- **Level 4** (Full)：探索性任务，包含头脑风暴
- **With-File 工作流**：文档化探索，支持多 CLI 协作
  - `brainstorm-with-file`：多视角创意生成
  - `debug-with-file`：假设驱动的调试
  - `analyze-with-file`：协作分析
- **Issue 工作流**：批量问题发现、规划、排队、执行

### 模式 6：问题报告

**触发条件**："ccw-issue"、"报告 bug"

**流程**：
1. 使用 AskUserQuestion 收集上下文
2. 生成结构化问题模板

## 数据源

唯一数据源：**[command.json](command.json)**

| 字段 | 用途 |
|------|------|
| `commands[]` | 带元数据的扁平命令列表 |
| `commands[].flow` | 关系（next_steps、prerequisites） |
| `commands[].essential` | 新手引导的必要标记 |
| `agents[]` | Agent 目录 |
| `essential_commands[]` | 核心命令列表 |

### Source 路径格式

`source` 字段是相对路径（从 `skills/ccw-help/` 目录）：

```json
{
  "name": "lite-plan",
  "source": "../../../commands/workflow/lite-plan.md"
}
```

## 斜杠命令

```bash
/ccw "task description"          # 自动选择工作流并执行
/ccw-help                        # 通用帮助入口
/ccw-help search <keyword>       # 搜索命令
/ccw-help next <command>         # 获取下一步建议
/ccw-issue                       # 问题报告
```

### CCW 命令示例

```bash
/ccw "Add user authentication"          # → 自动选择 level 2-3
/ccw "Fix memory leak in WebSocket"     # → 自动选择 bugfix 工作流
/ccw "Implement with TDD"               # → 检测 TDD，使用 tdd-plan → execute → tdd-verify
/ccw "头脑风暴: 用户通知系统"          # → 检测 brainstorm，使用 brainstorm-with-file
/ccw "深度调试: 系统随机崩溃"          # → 检测 debug-file，使用 debug-with-file
/ccw "协作分析: 认证架构设计"          # → 检测 analyze-file，使用 analyze-with-file
```

## 维护

### 更新机制

CCW-Help Skill 支持通过用户确认对话框进行手动更新。

#### 如何更新

**方式 1：执行 Skill 时会弹出提示：**

```
Would you like to update CCW-Help command index?
- Yes: Run auto-update and regenerate command.json
- No: Use current index
```

**方式 2：手动更新**

```bash
cd D:/Claude_dms3/.claude/skills/ccw-help
python scripts/auto-update.py
```

此命令运行 `analyze_commands.py` 扫描 commands/ 和 agents/ 目录并重新生成 `command.json`。

#### 更新脚本

- **`auto-update.py`**：简单封装，运行 analyze_commands.py
- **`analyze_commands.py`**：扫描目录并生成命令索引
