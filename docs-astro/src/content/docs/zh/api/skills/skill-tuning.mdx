# Skill Tuning

通用 Skill 诊断与优化工具。检测和修复 Skill 执行问题，包括上下文爆炸、长尾遗忘、数据流中断和 Agent 协调失败。支持 Gemini CLI 进行深度分析。触发关键词："skill tuning"、"tune skill"、"skill diagnosis"、"optimize skill"、"skill debug"。

## 概览

| 属性 | 值 |
|------|-----|
| **名称** | `skill-tuning` |
| **工具** | `Task`, `AskUserQuestion`, `Read`, `Write`, `Bash`, `Glob`, `Grep`, `mcp__ace-tool__search_context` |

## 检测的核心问题

| 优先级 | 问题 | 根因 | 修复策略 |
|--------|------|------|---------|
| **P0** | 编写违规 | 中间文件、状态膨胀、文件中转 | eliminate_intermediate, minimize_state |
| **P1** | 数据流中断 | 分散状态、格式不一致 | state_centralization, schema_enforcement |
| **P2** | Agent 协调 | 脆弱链条、无错误处理 | error_wrapping, result_validation |
| **P3** | 上下文爆炸 | 无限历史、完整内容传递 | sliding_window, path_reference |
| **P4** | 长尾遗忘 | 早期约束丢失 | constraint_injection, checkpoint_restore |
| **P5** | Token 消耗 | 冗余提示、状态膨胀 | prompt_compression, lazy_loading |

## 工作流

| 步骤 | 动作 | 编排器决策 | 输出 |
|------|------|-----------|------|
| 1 | `action-init` | status='pending' | 备份、会话创建 |
| 2 | `action-analyze-requirements` | 初始化后 | 所需维度 + 覆盖范围 |
| 3 | 诊断（6 种类型） | 关注区域 | state.diagnosis.\{type\} |
| 4 | `action-gemini-analysis` | 关键问题或用户请求 | 深度发现 |
| 5 | `action-generate-report` | 所有诊断完成 | state.final_report |
| 6 | `action-propose-fixes` | 发现问题 | state.proposed_fixes[] |
| 7 | `action-apply-fix` | 待处理修复 | 已应用 + 已验证 |
| 8 | `action-complete` | 质量门通过 | session.status='completed' |

## 动作参考

| 类别 | 动作 | 用途 |
|------|------|------|
| **设置** | action-init | 初始化备份、会话状态 |
| **分析** | action-analyze-requirements | 通过 Gemini CLI 分解用户请求 |
| **诊断** | action-diagnose-\{context,memory,dataflow,agent,docs,token_consumption\} | 检测特定类别问题 |
| **深度分析** | action-gemini-analysis | Gemini CLI：复杂/关键问题 |
| **报告** | action-generate-report | 整合发现 → final_report |
| **修复** | action-propose-fixes, action-apply-fix | 生成 + 应用修复 |
| **验证** | action-verify | 重新运行诊断，检查质量门 |
| **退出** | action-complete, action-abort | 最终化或回滚 |

完整动作详情：[phases/actions/](phases/actions/)

## 核心原则

1. **问题优先**：先诊断再修复
2. **数据驱动**：记录追踪、Token 计数、快照
3. **迭代**：多轮执行直到质量门通过
4. **可逆**：所有变更带备份检查点
5. **非侵入**：最小变更，最大清晰度

## 使用示例

```bash
# 基本 Skill 诊断
/skill-tuning "Fix memory leaks in my skill"

# 使用 Gemini 深度分析
/skill-tuning "Architecture issues in async workflow"

# 聚焦特定区域
/skill-tuning "Optimize token consumption and fix agent coordination"

# 自定义问题
/skill-tuning "My skill produces inconsistent outputs"
```

## 输出

完成后查看：
- `.workflow/.scratchpad/skill-tuning-{ts}/state.json` - 包含 final_report 的完整状态
- `state.final_report` - Markdown 摘要（在 state.json 中）
- `state.applied_fixes` - 已应用修复列表及验证结果
