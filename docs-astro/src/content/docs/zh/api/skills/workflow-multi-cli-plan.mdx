# 工作流多CLI计划 (Workflow Multi Cli Plan)

多CLI协作规划与执行技能 - 通过提示增强路由到 multi-cli-plan 或 lite-execute。触发词为 "workflow:multi-cli-plan", "workflow:lite-execute"。

## 概述

| 属性 | 值 |
|----------|-------|
| **名称** | `workflow-multi-cli-plan` |
| **工具** | `Skill`, `Task`, `AskUserQuestion`, `TodoWrite`, `Read`, `Write`, `Edit`, `Bash`, `Glob`, `Grep`, `mcp__ace-tool__search_context` |

# 工作流多CLI计划 (Workflow Multi-CLI Plan)

统一的多CLI协作规划与执行技能。根据触发词路由到 multi-cli-plan (ACE 上下文 + 多CLI讨论 + 计划生成) 或 lite-execute (执行引擎)，并为两种模式提供提示增强。

## 架构概览

```
┌─────────────────────────────────────────────────────────┐
│  SKILL.md (路由 + 提示增强)                              │
│  → 检测模式 → 增强提示 → 分派到阶段                       │
└──────────────────────┬──────────────────────────────────┘
                       │
           ┌───────────┼───────────┐
           ↓                       ↓
     ┌──────────────┐        ┌───────────┐
     │multi-cli-plan│        │lite-execute│
     │   阶段 1     │        │  阶段 2    │
     │  规划+执行   │─交接──→│ 独立运行   │
     └──────────────┘        └───────────┘
```

## 模式检测与路由

```javascript
const args = $ARGUMENTS
const mode = detectMode()

function detectMode() {
  if (skillName === 'workflow:lite-execute') return 'execute'
  return 'plan'  // 默认: workflow:multi-cli-plan
}
```

**路由表**:

| 触发词 | 模式 | 阶段文档 | 描述 |
|---------|------|----------------|-------------|
| `workflow:multi-cli-plan` | plan | [phases/01-multi-cli-plan.md](phases/01-multi-cli-plan.md) | 多CLI协作规划 (ACE 上下文 → 讨论 → 计划 → 执行) |
| `workflow:lite-execute` | execute | [phases/02-lite-execute.md](phases/02-lite-execute.md) | 独立执行 (内存 / 提示 / 文件) |

## 提示增强

在分派到目标阶段之前，增强上下文：

```javascript
// 步骤 1: 检查项目上下文文件
const hasProjectTech = fileExists('.workflow/project-tech.json')
const hasProjectGuidelines = fileExists('.workflow/project-guidelines.json')

// 步骤 2: 记录可用的上下文
if (hasProjectTech) {
  console.log('项目技术栈上下文可用: .workflow/project-tech.json')
}
if (hasProjectGuidelines) {
  console.log('项目指南上下文可用: .workflow/project-guidelines.json')
}

// 步骤 3: 分派到阶段
if (mode === 'plan') {
  // 读取 phases/01-multi-cli-plan.md 并执行
} else {
  // 读取 phases/02-lite-execute.md 并执行
}
```

## 执行流程

### 计划模式 (workflow:multi-cli-plan)

```
1. 解析标志 (-y/--yes, --max-rounds, --tools, --mode) 和任务描述
2. 通过项目上下文可用性增强提示
3. 读取 phases/01-multi-cli-plan.md
4. 执行 multi-cli-plan 流水线 (阶段文档内的阶段 1-5)
5. 阶段 5 内部通过 Skill 交接调用 workflow:lite-execute
```

### 执行模式 (workflow:lite-execute)

```
1. 解析标志 (--in-memory, -y/--yes) 和输入
2. 通过项目上下文可用性增强提示
3. 读取 phases/02-lite-execute.md
4. 执行 lite-execute 流水线 (输入检测 → 执行 → 审查)
```

## 用法

```bash
# 多CLI计划模式
/workflow:multi-cli-plan "实现用户认证"
/workflow:multi-cli-plan --yes "添加暗黑模式支持"
/workflow:multi-cli-plan "重构支付模块" --max-rounds=3 --tools=gemini,codex

# 执行模式 (独立)
/workflow:lite-execute "为 auth 添加单元测试"     # 提示描述
/workflow:lite-execute plan.json                     # 文件输入
/workflow:lite-execute --in-memory                   # 由 multi-cli-plan 内部调用
```
