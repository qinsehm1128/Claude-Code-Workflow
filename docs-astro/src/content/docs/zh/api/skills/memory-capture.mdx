# 记忆捕获 (Memory Capture)

统一的记忆捕获功能，可路由到会话压缩或快速提示模式。触发词："memory capture", "compact session", "save session", "quick tip", "memory tips", "记录", "压缩会话"。

## 概览

| 属性 | 值 |
|----------|-------|
| **名称** | `memory-capture` |
| **工具** | `mcp__ccw-tools__core_memory(*)`, `Read(*)`, `AskUserQuestion` |

## 参考

# 记忆捕获技能 (Memory Capture Skill)

统一的记忆捕获技能，可路由到两种执行模式：
- **压缩 (Compact)**: 将完整的会话记忆压缩成结构化文本，用于恢复
- **提示 (Tips)**: 用于想法、代码片段和见解的快速笔记

## 执行流程

### 步骤 1: 解析输入与路由

从用户输入中检测执行模式：

**自动路由规则** (按优先级排序):

| 信号 | 路由 | 示例 |
|--------|-------|---------|
| 关键词: compact, session, 压缩, recovery, 保存会话 | → 压缩 | "compact current session" |
| 关键词: tip, note, 记录, 快速 | → 提示 | "记录一个想法" |
| 包含 `--tag` 或 `--context` 标志 | → 提示 | `"笔记内容" --tag bug` |
| 短文本（`<100` 字符）+ 无会话关键词 | → 提示 | "记住要使用 Redis" |
| 模糊或无参数 | → **AskUserQuestion** | `/memory-capture` |

**当输入模糊时**, 使用 AskUserQuestion:

```
问题: "选择记忆捕获模式"
选项:
  1. Compact - 压缩当前完整会话记忆（用于会话恢复）
  2. Tips - 快速记录一条笔记/想法/提示
```

### 步骤 2: 执行选定阶段

根据路由结果，读取并执行相应的阶段：

- **压缩模式** → Ref: [phases/01-compact.md](phases/01-compact.md)
- **提示模式** → Ref: [phases/02-tips.md](phases/02-tips.md)

**阶段参考文档** (在阶段执行时按需读取):

| 模式 | 文档 | 目的 |
|------|----------|---------|
| 压缩 | [phases/01-compact.md](phases/01-compact.md) | 完整的会话记忆压缩和结构化导出 |
| 提示 | [phases/02-tips.md](phases/02-tips.md) | 带标签和上下文的快速笔记 |

### 步骤 3: 通过 core_memory 保存

两个阶段都汇集到相同的存储机制：

```javascript
mcp__ccw-tools__core_memory({
  operation: "import",
  text: structuredText  // 由选定阶段生成
})
```

## 核心规则

1. **单阶段执行**: 每次调用只执行一个阶段 - 绝不两个都执行
2. **内容忠实**: 阶段文件包含完整的执行细节 - 严格遵循它们
3. **绝对路径**: 输出中的所有文件路径必须是绝对路径
4. **不作总结**: 压缩模式逐字保留完整的计划 - 绝不缩写
5. **速度优先**: 提示模式应快速 - 最小化分析开销

## 输入处理

### 压缩模式输入
- 可选: `"会话描述"` 作为补充上下文
- 示例: `/memory-capture compact` 或 `/memory-capture "完成了 auth 模块"`

### 提示模式输入
- 必需: `<笔记内容>` - 提示/笔记的文本
- 可选: `--tag <tag1,tag2>` 用于分类
- 可选: `--context <context>` 用于关联代码/功能参考
- 示例: `/memory-capture tip "使用 Redis 进行速率限制" --tag config`

## 数据流

```
用户输入
    │
    ├─ [检测到 compact] → 读取 phases/01-compact.md
    │                     → 分析会话 → 生成结构化文本
    │                     → core_memory 导入 → 报告恢复 ID
    │
    └─ [检测到 tips] → 读取 phases/02-tips.md
                        → 解析参数 → 收集上下文 → 生成提示文本
                        → core_memory 导入 → 用 ID + 标签确认
```

## 错误处理

| 错误 | 操作 |
|-------|--------|
| core_memory 导入失败 | 重试一次，然后报告错误并附上结构化文本以供手动保存 |
| 无会话上下文 (压缩模式) | 警告用户，使用可用信息生成 |
| 笔记内容为空 (提示模式) | 通过 AskUserQuestion 要求用户提供内容 |
| 路由模糊 | 默认使用 AskUserQuestion - 绝不猜测 |
