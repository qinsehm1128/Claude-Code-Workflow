## 执行流程

### 步骤 1: 解析输入与路由

从用户输入中检测执行模式：

**自动路由规则** (按优先级排序):

| 信号 | 路由 | 示例 |
|--------|-------|---------|
| 显式的子命令 token | → 直接分发 | `update-full --tool qwen` |
| 关键词: full, 全量, all, entire + update/claude | → update-full | "全量更新claude" |
| 关键词: related, changed, 增量, diff + update/claude | → update-related | "更新变更模块" |
| 关键词: single, module, 单模块 + 类路径的 token | → update-single | "更新 src/auth 模块" |
| 关键词: docs, documentation, 文档 + full/all/全量 | → docs-full | "全量生成文档" |
| 关键词: docs, documentation, 文档 + related/changed/增量 | → docs-related | "增量生成文档" |
| 模糊或无参数 | → **AskUserQuestion** | `/memory-manage` |

有效的子命令 tokens: `update-full`, `update-related`, `update-single`, `docs-full`, `docs-related`

**直接分发示例**:
```
输入 = "update-full --tool qwen"
  → 子命令 = "update-full", 剩余参数 = "--tool qwen"
  → 读取 phases/01-update-full.md, 执行

输入 = "update-single src/auth --tool gemini"
  → 子命令 = "update-single", 剩余参数 = "src/auth --tool gemini"
  → 读取 phases/03-update-single.md, 执行
```

**当输入模糊或无参数时**，进入步骤 2。

### 步骤 2: 交互式需求评估

**问题 1 — 确定内容类别**:

```

```

**问题 2a — CLAUDE.md 管理范围** (如果用户选择了 CLAUDE.md):

```
AskUserQuestion({

    header: "范围",
```

## 共享配置

### 工具回退层级

所有子命令共享相同的回退逻辑：

```
--tool gemini  →  [gemini, qwen, codex]  // 默认
--tool qwen    →  [qwen, gemini, codex]
--tool codex   →  [codex, gemini, qwen]
```

### 通用参数

| 参数 | 描述 | 默认值 | 使用方 |
|-----------|-------------|---------|---------|
| `--tool <gemini\|qwen\|codex>` | 主要的 CLI 工具 | gemini | 所有 |
| `--path <dir>` | 目标目录 | . | update-full, docs-full |
| `<path>` (位置参数) | 模块路径 | _(必需)_ | update-single |

### 批处理阈值

| 子命令 | 直接执行 | Agent 批处理 | 批处理大小 |
|-------------|-----------------|-------------|------------|
| update-full | `<20` 模块 | `>=20` 模块 | 4/agent |
| update-related| `<15` 模块 | `>=15` 模块 | 4/agent |
| update-single | 总是单个 | 不适用 | 1 |
| docs-full | `<20` 模块 | `>=20` 模块 | 4/agent |
| docs-related | `<15` 模块 | `>=15` 模块 | 4/agent |

## 核心规则

1. **先路由后执行**: 在任何执行之前确定子命令
2. **阶段文档即真理**: 所有执行逻辑都存在于阶段文档中，路由只负责分发
3. **按需读取**: 只读取选定的阶段文档，绝不全部加载
4. **参数透传**: 将剩余参数原封不动地转发给子命令
5. **用户确认**: 每个子命令处理自己的计划展示和 y/n 确认

## 错误处理

| 错误 | 解决方案 |
|-------|------------|
| 未知子命令 | 回退到交互式流程 |
| 阶段文档未找到 | 报告文件路径错误并中止 |
| update-single 缺少路径 | 通过问题 3 提示用户 |
| 子命令执行失败 | 遵循该阶段文档自身的错误处理逻辑 |
