# Skills 参考

CCW Skills 是可复用的能力模块，可通过斜杠命令或关键词触发。每个 Skill 封装了一种特定的开发工作流模式。

## 可用 Skills

| Skill | 描述 |
|-------|------|
| [Brainstorm](/zh/docs/api/skills/brainstorm) | 统一头脑风暴技能，支持自动流水线和单角色分析双模式。 |
| [Ccw Help](/zh/docs/api/skills/ccw-help) | CCW 命令帮助系统 |
| [Copyright Docs](/zh/docs/api/skills/copyright-docs) | 生成符合中国版权保护中心标准的软件著作权设计说明书 |
| [Flow Coordinator](/zh/docs/api/skills/flow-coordinator) | 模板驱动的工作流协调器，具有最小状态追踪 |
| [Issue Discover](/zh/docs/api/skills/issue-discover) | 统一的问题发现与创建 |
| [Issue Manage](/zh/docs/api/skills/issue-manage) | 菜单驱动的交互式问题管理 CRUD 操作 |
| [Issue Resolve](/zh/docs/api/skills/issue-resolve) | 带来源选择的统一问题解决流水线 |
| [Memory Capture](/zh/docs/api/skills/memory-capture) | 统一记忆捕获路由，支持会话压缩与快速提示。 |
| [Memory Manage](/zh/docs/api/skills/memory-manage) | 统一记忆管理技能，支持全量/增量/单模块更新。 |
| [Project Analyze](/zh/docs/api/skills/project-analyze) | 多阶段迭代项目分析，支持 Mermaid 图表 |
| [Review Code](/zh/docs/api/skills/review-code) | 多维度代码审查，生成结构化报告 |
| [Review Cycle](/zh/docs/api/skills/review-cycle) | 统一多维度代码审查，支持自动修复编排 |
| [Skill Generator](/zh/docs/api/skills/skill-generator) | 用于创建新 Claude Code Skills 的元技能，支持可配置执行模式 |
| [Skill Tuning](/zh/docs/api/skills/skill-tuning) | 通用 Skill 诊断与优化工具 |
| [Software Manual](/zh/docs/api/skills/software-manual) | 生成 TiddlyWiki 风格的交互式 HTML 软件手册，支持截图、API 文档和多层级代码示例 |
| [Spec Generator](/zh/docs/api/skills/spec-generator) | 6 阶段需求文档生成器，可生成产品简报、PRD、架构与史诗故事。 |
| [Team Command Designer](/zh/docs/api/skills/team-command-designer) | 按团队协作模式设计并生成团队命令。 |
| [Team Lifecycle](/zh/docs/api/skills/team-lifecycle) | 统一团队生命周期技能，覆盖规范、实现、测试与审查。 |
| [Team Skill Designer](/zh/docs/api/skills/team-skill-designer) | 设计并生成统一团队 Skills，支持角色路由。 |
| [Workflow Execute](/zh/docs/api/skills/workflow-execute) | 工作流任务执行协调器，支持会话发现与并行执行。 |
| [Workflow Lite Plan](/zh/docs/api/skills/workflow-lite-plan) | 轻量规划与执行技能，支持在 lite-plan 与 lite-execute 间路由。 |
| [Workflow Multi Cli Plan](/zh/docs/api/skills/workflow-multi-cli-plan) | 多 CLI 协作规划与执行技能。 |
| [Workflow Plan](/zh/docs/api/skills/workflow-plan) | 统一规划技能，支持 4 阶段规划、验证与重规划。 |
| [Workflow Skill Designer](/zh/docs/api/skills/workflow-skill-designer) | 用于设计编排器+阶段结构化工作流 Skills 的元技能 |
| [Workflow Test Fix](/zh/docs/api/skills/workflow-test-fix) | 统一 test-fix 流水线，串联测试生成与迭代修复执行。 |
