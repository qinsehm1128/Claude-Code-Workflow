# Brainstorm

多角色头脑风暴，探索架构和新功能设计。

## 概览

| 属性 | 值 |
|----------|-------|
| **ID** | `brainstorm-auto-parallel` |
| **类型** | 头脑风暴 |
| **复杂度** | 高 |

## 用法

```bash
/workflow:brainstorm:auto-parallel "Design a real-time collaboration system" --count 5
/workflow:plan --session WFS-xxx
/workflow:plan-verify
/workflow:execute
```

## 描述

多角色头脑风暴：适合新功能/架构设计探索。
